## 六、已知局限

- CI 首过率只算“推送 tip 的第一次 Action”，不含本机测试结果；
  文档类推送在 workflow 加 paths 过滤前也会触发构建，早期数据偏噪。
- 无 token 访问 API 限 60 次/小时；脚本失败时 CI 一栏标“未知”，不会编数字。
