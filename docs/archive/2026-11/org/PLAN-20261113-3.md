## 二、重建原则（7 条）

1. **单会话单身份**：一个会话只当一个职位；宿主≠职位；职位不代宿主拍板。

3. **文档最小够用**：能合并的合并、能用脚本判定的不靠人记；新增文档必须有明确读者与维护者。
4. **活 / 历史 / 生成三分**：沿用已落地方案 A（`docs/README.md`）。
5. **零搬迁优先、渐进替代推倒重来**：先规则与索引，再小步移动；每步可回滚。
6. **可回滚**：每阶段记 before commit + 验收命令 + 回滚动作。
7. **流程服务功能**：文档与审查的产出要能换来更快的功能批次，否则砍流程。
